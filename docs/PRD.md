## 1. 产品概述

### 1.1 背景

面向以工程项目交付为核心业务的企业，项目从售前立项、投标、合同签订、采购施工、验收到回款，环节多、周期长、跨部门协作频繁。传统依赖 Excel 和线下沟通的方式存在进度不透明、成本失控、资料散落等问题。

本系统将项目全生命周期搬到线上，统一管理项目、任务、合同、财务、投标、知识资产，实现**进度可视、成本可控、资料可溯**。

### 1.2 产品目标

| 目标 | 说明 |
|------|------|
| 进度可视 | 通过任务管理 + 阶段步骤条呈现项目所处环节 |
| 成本可控 | 进出账双向记账，实时计算项目资金余额与核对差 |
| 协作高效 | 营销/解决方案/技术多部门按 SOP 分工协作 |
| 资料沉淀 | 合同、投标、产出物附件统一归档，知识库沉淀经验 |

### 1.3 目标用户

| 角色 | 核心诉求 |
|------|---------|
| 营销人员 | 投标管理、采购意向跟踪、回款跟进 |
| 项目经理 | 项目立项、任务分配、进度把控 |
| 技术/实施人员 | 任务执行、产出物提交 |
| 财务人员 | 进出账记录、开票、资金核对 |
| 管理层 | 项目概览、资金趋势、整体进度 |

## 3. 功能需求

### 3.1 项目管理

**功能描述**：管理工程项目的基础信息、资金、发票、负责人，是整个系统的核心实体。

| 编号 | 功能点 | 说明 |
|------|--------|------|
| P-01 | 项目新增 | 录入名称、编号、类型、地址、总款、负责人、周期 |
| P-02 | 项目编辑 | 修改项目信息，含交货期、质保期、优先级 |
| P-03 | 项目删除 | 删除项目并级联删除关联任务 |
| P-04 | 项目查询 | 按名称、编号、类型、状态、日期范围筛选 |
| P-05 | 发票信息管理 | 开票单位、税号、地址电话、开户行 |
| P-06 | 履约保证金 | JSON 存储缴纳金额、比例、缴纳/退回时间与状态 |
| P-07 | 附件管理 | 支持 doc/docx/xls/ppt/txt/pdf 上传 |
| P-08 | Excel 导出 | 列表数据导出，字典字段自动转中文 |

**关键字段**：项目类型（中标/自采/政采云/其他）、优先级（低/中/高）、状态（进行中/完结）。

### 3.2 任务管理（项目进度 SOP）

**功能描述**：项目内的任务记录，`task_type`（工作类型）即项目所处的 SOP 阶段。任务管理 Tab 顶部的步骤条按工作类型字典展示项目当前进度。

| 编号 | 功能点 | 说明 |
|------|--------|------|
| T-01 | 任务新增 | 关联项目，录入主题、工作类型、优先级、协作人员 |
| T-02 | 任务编辑/删除 | 维护任务详情、时间、附件 |
| T-03 | 按工作类型查询 | 字典驱动，将任务归类到对应阶段 |
| T-04 | 进度步骤条 | 顶部 el-steps 按工作类型显示项目走到哪一步 |
| T-05 | 时间轴视图 | 任务按阶段在时间轴上呈现 |

**工作类型阶段**（`sys_work_type` 字典）：需求沟通 → 方案策划 → 采购备货 → 收货验参 → 施工安装 → 质量管控 → 项目初验 → 项目终验 → 项目结算。

### 3.3 合同管理

| 编号 | 功能点 | 说明 |
|------|--------|------|
| C-01 | 合同新增 | 编号、名称、甲乙方信息、金额、签订日期、有效期 |
| C-02 | 合同类型 | 采购合同 / 项目合同 |
| C-03 | 合同状态 | 进行中 / 完结 |
| C-04 | 按项目查询 | 查询某项目下所有关联合同 |
| C-05 | 编辑/删除/导出 | 标准维护操作 |

### 3.4 财务管理

| F-03 | 时间段统计 | 按日期范围汇总收支 |
| F-04 | 项目资金概览 | 项目总额、未结算、入账、出账、核对差 |

## 4. 数据模型

### 4.1 核心实体关系

```
项目 (sys_oa_project)
 ├─1:N─> 任务 (sys_oa_task)
 ├─1:N─> 合同 (sys_oa_contract)
 └─1:N─> 进出账 (sys_oa_finance)
                └─1:N─> 进出账明细 (sys_oa_detail)

知识文章 (sys_oa_article) ─N:1─> 知识分类 (sys_oa_category)
采购意向 (sys_oa_purpose) ┄逻辑关联┄ 投标 (sys_oa_bid)
事件提醒 (sys_oa_remind)  独立表
```

### 4.2 主要数据表

| 表名 | 说明 | 主键 |
|------|------|------|
| sys_oa_project | 项目管理表 | project_id |
| sys_oa_task | 任务管理表 | task_id |
| sys_oa_contract | 合同管理表 | contract_id |
| sys_oa_finance | 进出账主表 | finance_id |
| sys_oa_detail | 进出账明细表 | detail_id |
| sys_oa_bid | 投标管理表 | bid_id |
| sys_oa_purpose | 采购意向表 | purpose_id |
| sys_oa_article | 知识文章表 | article_id |
| sys_oa_category | 知识分类表 | category_id |
| sys_oa_remind | 事件提醒表 | remind_id |

## 5. 核心业务流程

```
采购意向 ──> 投标项目 ──> 中标
                          │
                          ▼
              项目立项 (sys_oa_project)
                          │
          ┌───────────────┼───────────────┐
          ▼               ▼               ▼
      合同签订        任务执行        资金进出账
   (sys_oa_contract) (sys_oa_task)  (sys_oa_finance)
                          │
                          ▼
              任务按工作类型推进（需求沟通→...→项目结算）
                          │
                          ▼
                   验收完成 / 回款
                          │
                          ▼
                   知识库经验沉淀
```
